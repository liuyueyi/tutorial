# 图片水印

> 本文介绍 `image-plugin` 中的水印能力，对应的包为 `com.github.hui.quick.plugin.image.wrapper.wartermark`

先说一句：包名 `wartermark` 不是笔误，是历史遗留的拼写（water → warter），沿用了这么多年没改，新代码请照抄这个包名，否则类都找不到。

<!-- more -->

水印这个模块实际包含两个相反方向的能力：

1. **添加水印**（`WaterMarkWrapper`）：把 logo 图 + 签名文案合成一张水印，贴到原图的指定位置，或者铺满整个背景
2. **指定区域去水印**（`WaterMarkRemoveWrapper`）：告诉你水印的坐标和宽高，把这一块用像素化、颜色填充或背景色推算的方式抹掉

### I. 场景与设计思路

#### 1. 加水印

最常见的场景：公众号图床的图片右下角都有一行"公众号 logo + 作者签名"。用程序来做，拆开就是三步：

- **合成水印**：把 logo（可选）和文案（可选）画到一张透明画布上，得到一张小的水印图。logo 高度默认和文字等高，宽等比缩放；logo 和文字可以放同一行（`inline=true`），也可以上下两行
- **定位**：提供九宫格定位样式（左上、上中、右上、左中、正中、右中、左下、下中、右下），也可以直接传 `x`/`y` 精确坐标——只要 x、y 有一个大于 0，就优先用你传的坐标
- **贴图**：用 `AlphaComposite` 设置透明度后，把水印图画到原图上。`FILL_BG` 样式比较特殊，它会把水印平铺成一张覆盖原图的大图再贴上去，同时支持旋转角度

#### 2. 去水印

反过来，如果拿到一张图，上面有个你不想要的水印（比如别人家图床的签名），用 `WaterMarkRemoveWrapper`，把水印的矩形区域框出来，提供三种"抹掉"的策略：

- `fill`：直接用指定颜色盖掉
- `pixel`：对区域内的像素做马赛克均值处理，看起来像打码
- `bg`：根据水印上下相邻的背景色推算填充色，适合纯色背景的图，效果最自然

### III. 加水印使用示例

> 以下代码取自源码测试类 [WaterMarkWrapperTest.java](https://github.com/liuyueyi/quick-media/blob/master/plugins/image-plugin/src/test/java/com/github/hui/quick/plugin/test/WaterMarkWrapperTest.java)

#### 1. 全背景平铺水印（FILL_BG）

防遮挡最狠的一招，水印 45 度旋转、半透明、铺满整张图：

```java
@Test
public void testWaterMark() {
    try {
        BufferedImage img = WaterMarkWrapper.of("bg.png")   // 原图路径，请替换
                .setInline(true)                            // logo 与文案同一行
                .setWaterLogo("xcx.jpg")                    // 水印 logo，请替换
                .setWaterLogoHeight(50)                     // logo 显示高度，宽等比
                .setWaterInfo(" 图文小工具\n By 小灰灰Blog")   // 水印文案，\n 换行
                .setStyle(WaterMarkOptions.WaterStyle.FILL_BG)
                .setWaterColor(Color.LIGHT_GRAY)
                .setWaterOpacity(0.8f)                      // 透明度 0~1
                .setRotate(45)                              // 旋转角度
                .setPaddingX(80)                            // 平铺的水平间隔
                .setPaddingY(80)                            // 平铺的垂直间隔
                .build()
                .asImage();

        ImageIO.write(img, "jpg", new File("/tmp/FILL_BG.jpg"));
    } catch (Exception e) {
        e.printStackTrace();
    }
}
```

#### 2. 指定位置水印

不传 `style` 想自己定位置，可以直接给 `x`/`y`；或者用九宫格样式让它自动算：

```java
@Test
public void testPositionWaterMark() throws IOException {
    BufferedImage img = WaterMarkWrapper.of("bg.png")   // 原图路径，请替换
            .setInline(true)
            .setWaterLogo("xcx.jpg")                    // 请替换
            .setWaterLogoHeight(50)
            .setWaterColor(Color.WHITE)
            .setWaterInfo(" 图文小工具\n By 小灰灰Blog")
            .setX(50)                                   // 指定坐标，优先生效
            .setY(50)
            .setWaterOpacity(0.5f)
            .build()
            .asImage();

    ImageIO.write(img, "png", new File("/tmp/mark.png"));
}
```

如果既不传 `x`/`y`，也不传 `style`，`WaterStyle.getStyle(null)` 会兜底到 `OVERRIDE_RIGHT_BOTTOM`，也就是最常见的右下角签名。

#### 3. 九宫格样式一览

`WaterMarkOptions.WaterStyle` 的枚举值如下，`getStyle(String)` 按枚举名（大小写不敏感）匹配，匹配不到同样兜底右下角：

| 样式 | 位置 |
| --- | --- |
| `OVERRIDE_LEFT_TOP` | 左上角 |
| `OVERRIDE_TOP_CENTER` | 上居中 |
| `OVERRIDE_RIGHT_TOP` | 右上角 |
| `OVERRIDE_LEFT_CENTER` | 左中 |
| `OVERRIDE_CENTER` | 正中 |
| `OVERRIDE_RIGHT_CENTER` | 右中 |
| `OVERRIDE_LEFT_BOTTOM` | 左下角 |
| `OVERRIDE_BOTTOM_CENTER` | 下居中 |
| `OVERRIDE_RIGHT_BOTTOM` | 右下角 |
| `FILL_BG` | 全背景平铺 |

自动定位时边距固定为 10px；`FILL_BG` 场景下 x、y 不参与计算。

#### 4. 加水印参数说明

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `source` | 原图，支持路径或 `BufferedImage` | 必传 |
| `waterLogo` | 水印 logo 图，支持路径或 `BufferedImage` | 无 |
| `waterLogoHeight` | logo 显示高度，宽按原图比例换算 | 不传时取文字高度与 logo 原高中较小者 |
| `waterInfo` | 水印文案，`\n` 分多行 | 无 |
| `waterFont` | 水印字体 | `FontUtil.BIG_DEFAULT_FONT`（宋体 22 号） |
| `waterColor` | 水印文字颜色 | `Color.WHITE` |
| `inline` | logo 与文案是否同一行 | `true`；`false` 时 logo 上、文案下，水平居中 |
| `waterOpacity` | 透明度，0~1 | `1`（不透明） |
| `style` | 九宫格定位样式 | 未传坐标时兜底 `OVERRIDE_RIGHT_BOTTOM` |
| `x` / `y` | 水印绘制坐标 | 任一大于 0 则优先于 `style` 生效 |
| `rotate` | 水印旋转角度，自动对 360 取模 | `0` |
| `paddingX` / `paddingY` | `FILL_BG` 平铺时的水平/垂直间隔 | 50 / 60 |

### IV. 去水印使用示例

> 以下代码取自源码测试类 [WaterRemoveTest.java](https://github.com/liuyueyi/quick-media/blob/master/plugins/image-plugin/src/test/java/com/github/hui/quick/plugin/test/water/WaterRemoveTest.java)

三种去水印姿势，同一个水印区域，只换策略：

```java
@Test
public void testRemoveFill() throws IOException {
    // 下面这个 url 是微信图床的测试图，可替换为你自己的图
    String url = "https://mmbiz.qpic.cn/mmbiz_png/dYV9cAW65kYJ2uVS43GPVqNQcAtJqVCWhBmISJXF9KpNib7zicjIX7VFYnNccafC7LomzqIZKQe4A54RNicic9HTvw/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1";

    // 方式一：fill，指定颜色直接填充
    BufferedImage img = WaterMarkRemoveWrapper.of(url)
            .setType(WaterMarkRemoveTypeEnum.FILL.getType())
            .setWaterMarkH(47)          // 水印区域高
            .setWaterMarkW(189)         // 水印区域宽
            .setWaterMarkX(782)         // 水印区域左上角 x
            .setWaterMarkY(352)         // 水印区域左上角 y
            .setFillColor("0xff557ec6") // 填充色，支持 int 字符串
            .build()
            .asImage();
}
```

```java
@Test
public void testRemovePixel() throws IOException {
    String url = "https://mmbiz.qpic.cn/mmbiz_png/dYV9cAW65kYJ2uVS43GPVqNQcAtJqVCWhBmISJXF9KpNib7zicjIX7VFYnNccafC7LomzqIZKQe4A54RNicic9HTvw/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1";

    // 方式二：pixel，马赛克打码，pixelSize 是马赛克格子大小
    BufferedImage img = WaterMarkRemoveWrapper.of(url)
            .setType(WaterMarkRemoveTypeEnum.PIXEL.getType())
            .setWaterMarkH(47)
            .setWaterMarkW(189)
            .setWaterMarkX(782)
            .setWaterMarkY(352)
            .setPixelSize(8)
            .build()
            .asImage();
}
```

```java
@Test
public void testRemoveBg() throws IOException {
    String url = "https://mmbiz.qpic.cn/mmbiz_png/dYV9cAW65kYJ2uVS43GPVqNQcAtJqVCWhBmISJXF9KpNib7zicjIX7VFYnNccafC7LomzqIZKQe4A54RNicic9HTvw/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1";

    // 方式三：bg，用水印上下相邻的背景色均值填充，纯色背景下效果最自然
    BufferedImage img = WaterMarkRemoveWrapper.of(url)
            .setType(WaterMarkRemoveTypeEnum.BG.getType())
            .setWaterMarkH(47)
            .setWaterMarkW(189)
            .setWaterMarkX(782)
            .setWaterMarkY(352)
            .setUpDownRate(0.2F)   // 水印区域上下拆分比例，0.2 表示上部分占 20%
            .setDownRange(0.2f)    // 下部分取背景色的采样高度倍率
            .build()
            .asImage();
}
```

#### 去水印参数说明

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `img` | 原图，支持路径/base64/`BufferedImage` | 必传 |
| `waterMarkX` / `waterMarkY` | 水印区域左上角坐标，从图片左上角出发 | 必传 |
| `waterMarkW` / `waterMarkH` | 水印区域宽高 | 必传 |
| `type` | 处理策略 | `bg` |
| `fillColor` | `fill` 策略的填充色 | 白色 |
| `pixelSize` | `pixel` 策略的马赛克格子大小 | `10` |
| `upDownRate` | `bg` 策略中水印上下拆分比例，0~1 | `0.5`，超出自动截断 |
| `upRange` / `downRange` | `bg` 策略中上/下部分取背景色的采样范围倍率，如 1 表示取与对应部分等高的背景 | `1` |

### V. 适用场景与注意点

**适用场景：**

- 图床、素材站给上传图片批量加签名/版权水印
- `FILL_BG` 平铺 + 半透明，适合防盗图，部分遮挡也能保证图片可用
- 去水印适合清理合作方图片上多余的品牌角标，或者给自己图上之前加得不合适的水印做修补

**注意点：**

1. **加水印直接改的是原图对象**。`asImage()` 返回的就是传入的 `source` 本身（在其上绘制），如果你还需要无水印的原图，调用前先自己复制一份
2. **透明度是全局生效的**。`AlphaComposite.SRC_ATOP` 作用在整个绘制过程中，水印图上的 logo 和文字会一起半透明，不能分开调
3. **`FILL_BG` 的旋转是为了防露边**。平铺大图是按"原图最长边 + 水印单元尺寸 + 间隔"构造的正方形，旋转后裁掉超出部分也不会在角落露出空白；`rotate` 只对平铺后的整图旋转，单个水印的旋转在 `FILL_BG` 下不生效
4. **去水印的坐标要自己量**。水印区域是矩形框，框小了会留水印边缘，框大了会破坏更多画面；可以借助图片编辑工具读取像素坐标
5. **`bg` 策略对复杂背景效果差**。它是取水印上/下相邻区域的颜色均值来填充，渐变或纹理背景会有明显色块，这种情况用 `pixel` 打码反而更自然
6. **去水印落盘固定 jpg**。`WaterMarkRemoveWrapper.asFile()` 内部按 `jpg` 写文件，透明图会丢 alpha 通道；需要保透明请拿 `asImage()` 的返回值自己 `ImageIO.write` 成 png
7. **再次强调包名**。import 的时候是 `com.github.hui.quick.plugin.image.wrapper.wartermark`，少个 a，别手滑写成 water
